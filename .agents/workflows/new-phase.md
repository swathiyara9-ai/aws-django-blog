# Workflow: start or continue a build phase

Trigger: `/new-phase`

1. Open `docs/TASKS.md` and identify the current phase (first phase not fully checked).
2. Summarise in simple words: what this phase builds, why it matters, and how it connects to the previous phase.
3. List the exact files to create or change and the commands to run. Wait for confirmation.
4. Build in small steps. After each step: show the command, the expected result, and a short explanation of any new concept.
5. When the phase is complete, give a manual test checklist and wait for Swathi to confirm results.
6. Update `docs/TASKS.md` (tick boxes) and add an entry to `docs/LEARNING_LOG.md` (concepts learned, likely interview questions, simple answers).
7. Ask whether to continue to the next phase.
