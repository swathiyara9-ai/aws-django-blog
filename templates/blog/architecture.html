Amazon Linux 2023 instances running Gunicorn WSGI and Django 5.2. Protected in private subnets with strict security groups.

Managed relational database deployed in private subnets. Encrypted at rest via AWS KMS with automated backups.

  • Local fallback: SQLite (dev/test)

Serverless AI inference using Amazon Nova Lite (amazon.nova-lite-v1:0) in Sydney for smart titles, hashtags, and summaries.

  • Strictly scoped IAM InvokeModel policy

Production Security Architecture Principles

All database and application instances reside strictly within private subnets. The ALB is the sole entry point exposed to the public internet (0.0.0.0/0 on 80/443). AWS access keys are never placed in configuration files or codebases; instead, permissions are granted through IAM Instance Profiles and temporary role credentials managed by AWS STS.
